# HiSolver

**HiSolver** (Horndeski Inflation Solver) is a numerical pipeline for computing primordial power spectra in general Horndeski scalar-tensor inflation theories. It combines a symbolic algebra layer written in SymPy with fast C++ solvers for the background evolution and the Mukhanov-Sasaki equation, and is designed to be model-agnostic: you specify your Horndeski functions $G_2, G_3, G_4, G_5$ once, and the pipeline derives and generates all the necessary equations automatically.

The code was developed as part of a thesis on Non-Minimal Derivative Coupling (NMDC) inflation, where the inflaton kinetic term couples to the Einstein tensor. It has been validated against the analytical results of Yang et al. (2016, Class. Quantum Grav. 33, 205001) and tested against ACT DR6 and Planck 2018 observational constraints.

---

## Physics background

The most general scalar-tensor theory with second-order field equations in four dimensions is the Horndeski action:

$$S = \int d^4x \sqrt{-g} \sum_{i=2}^{5} \mathcal{L}_i$$

where $\mathcal{L}_i$ are Lagrangian densities built from the scalar field $\phi$, its kinetic term $X = -\frac{1}{2}\nabla_\mu\phi\nabla^\mu\phi$, and arbitrary functions $G_i(\phi, X)$. General Relativity with a canonical scalar field is recovered by setting $G_2 = X - V(\phi)$, $G_3 = 0$, $G_4 = M_{\rm pl}^2/2$, $G_5 = 0$.

HiSolver works in flat FLRW spacetime and uniform field gauge. The background equations (Friedmann + Klein-Gordon) and the quadratic perturbation action are derived symbolically from the user-specified $G_i$ functions. The key perturbation coefficients are:

- $Q_s$: scalar kinetic coefficient (ghost stability: $Q_s > 0$)
- $c_s^2$: scalar sound speed squared (gradient stability: $c_s^2 > 0$)
- $Q_T$: tensor kinetic coefficient
- $c_T^2$: tensor propagation speed squared

The Mukhanov-Sasaki equation is solved mode by mode in e-fold time $N = \ln(a/a_0)$, with Bunch-Davies initial conditions imposed deep inside the horizon and the power spectrum evaluated after horizon crossing.

## Installation

HiSolver requires Python 3.9+ and a C++17 compiler.

**Python dependencies:**

```bash
pip install sympy numpy
```

**Clone the repository:**

```bash
git clone https://github.com/aayush21-work/hisolver.git
cd hisolver
```

No additional installation is needed. The Python package lives in `hisolver/` and the C++ solvers are compiled locally.

## Quick start

### Step 1: Define your Horndeski model

Open `hisolver/codegen/cpp_emitter.py` and find the `__main__` block at the bottom. Specify your $G_i$ functions as SymPy expressions in `phi_sym` and `X_sym`:

```python
from hisolver.symbols import phi_sym, X_sym, Mpl, M
from sympy import Function

V   = Function('V')(phi_sym)   # potential (implemented in model_potential.hpp)

# Example: Einstein tensor NMDC model
# Action: R/2 - X/2 - V - X*G^{mu nu} phi_mu phi_nu / M^2
G2  = X_sym - V
G3  = 0 * X_sym
G4  = Mpl**2/2 + X_sym/M**2   # NMDC coupling lives here
G5  = 0 * X_sym

params = {"Mpl": 1.0, "M": 1e-5}   # numerical values of parameters
```

For a canonical scalar field in GR:

```python
G2  = X_sym - V
G3  = 0 * X_sym
G4  = Mpl**2 / 2
G5  = 0 * X_sym
```

For a Galileon model:

```python
c   = symbols('c')
G2  = X_sym - V
G3  = c * X_sym
G4  = Mpl**2 / 2
G5  = 0 * X_sym
```

### Step 2: Define your potential

Edit `model_potential.hpp` to implement `V_phi(phi)` and `dV_phi(phi)`:

```cpp
// Plateau potential: V = V0 * phi^2 / (m^2 + phi^2)
static constexpr double V0    = 4.3e-10;
static constexpr double m_phi = 1.0;

inline double V_phi(double phi) {
    double p2 = phi*phi, m2 = m_phi*m_phi;
    return V0 * p2 / (m2 + p2);
}
inline double dV_phi(double phi) {
    double p2 = phi*phi, m2 = m_phi*m_phi;
    return V0 * 2.0*m2*phi / ((m2+p2)*(m2+p2));
}
```

### Step 3: Generate the C++ header

```bash
python -m hisolver.codegen.cpp_emitter
```

This reads your $G_i$ definitions, derives all background and perturbation equations symbolically, and writes `model_generated.hpp`. You can inspect the generated functions before compiling.

### Step 4: Set initial conditions

In `background.cpp`, set the initial field value. A larger `phi` gives more e-folds:

```cpp
double phi  = 4.5;   // gives ~60 e-folds with the plateau potential + NMDC M=1e-5
double dphi = slow_roll_dphi(phi);
```

### Step 5: Build and run

```bash
make run
```

This compiles both solvers, runs the background evolution, and then solves the Mukhanov-Sasaki equation for 100 modes. Results are written to:

- `background.dat` - full background trajectory
- `power_spectrum.dat` - $\mathcal{P}_\mathcal{R}(k)$ and $\mathcal{P}_T(k)$ vs $k/k_*$
- `spectra_summary.dat` - $A_s$, $n_s$, $r$, $n_T$ at the pivot scale

## Output format

**`background.dat`** columns:

| Column | Quantity |
|--------|---------|
| N | e-fold time $\ln(a/a_0)$ |
| phi | inflaton field $\phi$ |
| dphi | $\dot\phi$ (cosmic time derivative) |
| H | Hubble parameter |
| logH | $\ln H$ |
| epsilon | slow-roll parameter $\epsilon_H = -\dot H/H^2$ |
| QT | tensor kinetic coefficient |
| cT2 | tensor speed squared $c_T^2$ |
| Qs | scalar kinetic coefficient |
| cs2 | scalar sound speed squared $c_s^2$ |

**`spectra_summary.dat`:**

```
A_s = 2.1e-9       # scalar amplitude at pivot scale
n_s = 0.965        # scalar spectral index
r   = 0.006        # tensor-to-scalar ratio
A_T = 1.3e-11      # tensor amplitude
n_T = -0.00075     # tensor spectral tilt
```

## Checking stability

Before trusting the power spectrum, verify the ghost and gradient stability conditions along the inflationary trajectory by plotting the background output:

```python
import numpy as np
import matplotlib.pyplot as plt

d = np.loadtxt('background.dat', comments='#')
N, Qs, cs2, QT, cT2 = d[:,0], d[:,8], d[:,9], d[:,6], d[:,7]

fig, axes = plt.subplots(2, 2, figsize=(10, 7))
axes[0,0].plot(N, Qs);   axes[0,0].set_title('Qs (> 0 = no scalar ghost)')
axes[0,1].plot(N, cs2);  axes[0,1].set_title('cs2 (> 0 = gradient stable)')
axes[1,0].plot(N, QT);   axes[1,0].set_title('QT (> 0 = no tensor ghost)')
axes[1,1].plot(N, cT2);  axes[1,1].set_title('cT2 (> 0 = gradient stable)')
for ax in axes.flat:
    ax.axhline(0, color='r', linestyle='--')
    ax.set_xlabel('N')
plt.tight_layout()
plt.savefig('stability.png')
```

## Verifying your model symbolically

You can inspect all derived equations before running any C++ code. Open a Jupyter notebook in the `hisolver/` directory:

```python
import sys
sys.path.insert(0, '/path/to/hisolver')

from sympy import Function, symbols, simplify
from sympy.printing.latex import LatexPrinter
from IPython.display import display, Math

from hisolver.symbols import phi_sym, X_sym, Mpl, M, dphi, H
from hisolver.algebra.background import (
    energy_density, KG_coefficients, substitute_model
)
from hisolver.algebra.perturbations import substitute_perturbations

V = Function('V')(phi_sym)
G2 = X_sym - V
G3 = 0*X_sym
G4 = Mpl**2/2 + X_sym/M**2
G5 = 0*X_sym

# Check Friedmann equation
rho = substitute_model(energy_density(), G2, G3, G4, G5)
rho = rho.subs(X_sym, dphi**2/2)
display(Math(r'3H^2 = ' + latex(simplify(rho + 3*Mpl**2*H**2))))

# Check perturbation coefficients
res = substitute_perturbations(G2, G3, G4, G5)
display(Math(r'Q_T = ' + latex(res['QT'])))
display(Math(r'c_T^2 = ' + latex(res['cT2'])))
```

## Supported Horndeski models

Any model expressible in the Horndeski framework can be used. Some examples tested with HiSolver:

| Model | G4 | Notes |
|---|---|---|
| GR + canonical scalar | $M_{\rm pl}^2/2$ | Standard inflation, recovered as GR limit |
| Einstein tensor NMDC | $M_{\rm pl}^2/2 + X/M^2$ | Gravitationally enhanced friction |
| k-inflation | $M_{\rm pl}^2/2$ with $G_2 = X^2/M^4 - V$ | Non-canonical kinetic term |
| Kinetic gravity braiding | $M_{\rm pl}^2/2$ with $G_3 = cX$ | Galileon-type friction |
| Beyond Horndeski (GLPV) | planned | $F_4, F_5$ extension in progress |

---

## Extending to beyond-Horndeski (GLPV)

The GLPV (Gleyzes-Langlois-Piazza-Vernizzi) theory extends Horndeski with two additional functions $F_4(\phi, X)$ and $F_5(\phi, X)$. Support for these is planned as the next major feature. The algebra layer is already structured to accommodate this extension with minimal changes to `perturbations.py`.

## Known limitations

- The `H_of` Newton solver assumes the Friedmann equation has a unique positive root. For models where $\rho_\phi$ decreases steeply with $H$, convergence may require a better initial guess.

- The `ddphi_rhs` function is computed by passing `dH = -epsilon*H^2` to avoid a large numerical cancellation that occurs in the Raychaudhuri-derived formula at slow roll. This is mathematically exact but worth being aware of.

- The Mukhanov-Sasaki solver uses fixed step size `dN = 1e-4`. For models with sharp features in the potential (resonance inflation, USR) a smaller step or adaptive stepping may be needed.

- `A_s` in absolute units depends on `V0`. The spectral index `n_s` and tensor-to-scalar ratio `r` are insensitive to this overall normalization and are the primary outputs to compare against observations.
